# Quick Start

Use the [README quick start](https://github.com/alessiosavi/demand-forecast/blob/main/README.md#quick-start) for the current tiny CPU
example: generate a long-format panel, train with `--config` and `--out`, then
forecast from the saved bundle.

Current contracts and implementation details are maintained in:

- The [Settings schema](https://github.com/alessiosavi/demand-forecast/blob/main/demand_forecast/config/settings.py) for YAML fields,
  defaults and validation.
- The [frozen protocol](protocol.md) for benchmark configuration, data, model,
  training and evaluation contracts.

Use the linked README, Settings schema and frozen protocol for current commands and contracts.
