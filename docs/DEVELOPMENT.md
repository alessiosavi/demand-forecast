# Development

Start with the [README quick start](https://github.com/alessiosavi/demand-forecast/blob/main/README.md#quick-start) for a working CPU
example and its [development checks](https://github.com/alessiosavi/demand-forecast/blob/main/README.md#development-and-latency) for
tests, linting and formatting. Benchmark tests require the optional `bench` extra.

Use these sources when changing the current implementation:

- The [Settings schema](https://github.com/alessiosavi/demand-forecast/blob/main/demand_forecast/config/settings.py) for configuration
  fields and validation.
- The [frozen protocol](protocol.md) for benchmark configuration, data, model,
  training and evaluation contracts.

Use the linked README, Settings schema and frozen protocol for current commands and contracts.
