# API Reference

The [README quick start](https://github.com/alessiosavi/demand-forecast/blob/main/README.md#quick-start) shows the current training and
forecast commands. Its [module inventory](https://github.com/alessiosavi/demand-forecast/blob/main/README.md#package-modules) identifies
the implemented package paths, including `core.run`, `core.training`,
`core.bundle`, and `inference.predictor`.

Use these sources for the current API contract:

- The [Settings schema](https://github.com/alessiosavi/demand-forecast/blob/main/demand_forecast/config/settings.py) for configuration
  models, defaults and validation.
- The [frozen protocol](protocol.md) for benchmark configuration, data, model,
  training and evaluation contracts.

Use the linked README, Settings schema and frozen protocol for current commands and contracts.
